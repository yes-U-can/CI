# CI

Legacy public image assets for archived SICP Google Apps Script deployments.

This repository is intentionally kept public because older GAS versions load logo and banner images from these raw GitHub URLs:

- `https://raw.githubusercontent.com/yes-U-can/CI/main/SICP-banner-777777.png`
- `https://raw.githubusercontent.com/yes-U-can/CI/main/SICP-icon-4E73AA.png`

Do not delete, privatize, or rename this repository unless those archived deployments are intentionally allowed to lose their images.
